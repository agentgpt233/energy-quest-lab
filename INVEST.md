# Инвест-лендинг — medicalmind.ru/invest/

Статическая страница (HTML + CSS + vanilla JS, без сборки) лежит в `public/invest/`.
Vite копирует `public/` в `dist` как есть, поэтому страница живёт отдельно от React-приложения
и не ломается при его пересборке.

```
public/invest/
├── index.html          # разметка и метатеги
├── styles.css          # стили и анимации
├── app.js              # ← объект METRICS + рендер
└── assets/             # скриншоты, логотип, og:image, шрифты Inter
```

## Как обновить цифры

1. Откройте `public/invest/app.js` — объект `METRICS` в самом начале файла — и поправьте нужные значения.
2. Обновите там же `updated: '18 августа 2026'` на новую дату и сделайте `git push` в `main` —
   GitHub Actions пересоберёт сайт за 1–2 минуты.

Больше числа нигде не дублируются: метрики, диаграмма «Использование средств», дорожная карта,
бизнес-модель, команда и строка раунда рендерятся из `METRICS`.

## Что осталось подставить

| Что | Где | Как |
|-----|-----|-----|
| Питч-дек PDF | `METRICS.deckUrl` | положить файл в `public/invest/assets/`, вписать путь — кнопка сама станет «Скачать питч-дек» (пока она «Запросить питч-дек» и открывает письмо) |
| ID Яндекс.Метрики | `METRICS.yandexMetrikaId` + закомментированный блок в конце `index.html` | вписать номер счётчика в обоих местах и раскомментировать блок; цели `invest_mailto`, `invest_deck`, `invest_rustore` отправляются автоматически |
| ФИО научного совета | `METRICS.boardText` | заменить обезличенную формулировку на конкретные фамилии |
| Ещё скриншоты | `METRICS.gallery` | положить `имя.webp` и `имя.jpg` (ширина 560 px) в `assets/`, добавить строку в массив |
